# signalk-boatinstrument-plugin

Companion SignalK Plugin for the [Boat Instrument](https://github.com/philseeley/boatinstrument#boat-instrument) v0.10.0+.

No configuration is required.

See the [Known Issue](https://philseeley.github.io/docs/boatinstrument/main.html#not-using-the-signalk-boatinstrument-plugin) if you do not, or cannot, install the plugin.
